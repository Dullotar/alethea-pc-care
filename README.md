# Alethea PC Care

Programa de manutenção para Windows 10 e 11: limpeza, segurança, atualizações, drivers, programas, desempenho e Modo jogo.
Você analisa, revisa e escolhe o que corrigir; nada é alterado na análise, e um ponto de restauração é criado antes de qualquer correção.

## Baixar

Abra a [página de versões](https://github.com/Dullotar/alethea-pc-care/releases/latest) e escolha:

- **Alethea-x.y.z-instalador.exe**: instala em `C:\Program Files\Alethea PC Care`. Executar de novo atualiza e mantém suas configurações.
- **Alethea-x.y.z.zip** (portátil): extraia em qualquer pasta, inclusive um pendrive, e execute `Alethea.exe`.
- **Alethea-x.y.z.sha256.txt**: códigos para conferir se o arquivo baixado está íntegro.

O próprio programa avisa quando há versão nova (Configurações > Sobre).

## Aviso do Windows ao abrir

O programa não tem assinatura digital, então o Windows pode mostrar "O Windows protegeu seu PC".
Clique em **Mais informações** e depois em **Executar mesmo assim**.
